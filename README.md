# 我的系统 · 原型 V1

个人成长产品「我的系统」的独立原型版本（WorkBuddy 线），纯前端静态实现，无构建依赖。

- 产品名：**我的系统**（与用户给系统起的名字是两个概念）
- 系统角色统一称为「系统」，不使用「慢慢」「伙伴」等旧设定
- 移动端优先 · 深色科技风 · 冰蓝冷色强调 · 三主页面结构（系统 / 任务 / 我的）

## 运行方式

方式一：直接用浏览器打开 `index.html`。

方式二：本地服务器（推荐）：

```bash
python -m http.server 8791 --directory my-system
# 访问 http://localhost:8791
```

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面入口：初始化引导、三个主页面、全部弹出面板 |
| `style.css` | 深色科技风样式、SVG 形象动画 |
| `app.js` | 数据层（localStorage）、页面渲染、愿望澄清向导、任务/积分/兑换逻辑 |
| `appearance.js` | 8 种系统形态 SVG、参数化用户彩绘 SVG、描述关键词匹配 |
| `test-smoke.js` | Node 冒烟测试（桩掉 DOM 跑通主要流程） |

## 核心流程

1. **首次进入**：6 步初始化（称呼 → 系统名 → 性格 → 系统形态 → 用户形象粗选 → 现有目标，可跳过）
2. **愿望澄清**：系统页输入愿望（或直接选方向）→ 选项式向导：方向 → 现状 → 期望 → 每日投入 → 期限 → 计划预览 → 创建
3. **执行**：任务页查看（全部/进行中/已完成）→ 任务详情 → 文字记录 + 可选照片（仅记文件名）→ 提交验证 → 获得积分
4. **成长**：20 积分兑换 20 成长值（演示参数），每 100 成长值升 1 级，等级提升系统辉光强度
5. **捏脸**：我的页 → 编辑形象：发型/发色/肤色/服装/眼镜/脸宽/眼型/身高/体重实时预览，支持一句话描述匹配初稿

## 8 种系统形态

核芯 · 星轨 · 晶簇 · 流光 · 机灵 · 云核 · 脉冲 · 镜像（均为本地 SVG 动画，非 AI 生成）

## 能力边界（重要）

**已实现（本地原型能力）**
- 三主页面、目标向导、规则任务生成、筛选、打卡、积分、兑换、等级
- 系统形态切换、用户彩绘捏脸、实时预览、保存/取消/恢复默认
- localStorage 持久化、JSON 导出、刷新后保留

**演示（规则模拟，不是真实 AI，不得对外宣传为 AI 能力）**
- 目标拆解：关键词 + 模板规则
- 任务验证：提交即通过
- 照片：仅记录文件名，不上传不存储不识别
- 性格适应：开关占位
- 兑换比例与升级数值：演示参数

**未实现（需要后端 / AI 服务）**
- 真实对话理解、模糊愿望智能澄清、个性化计划、智能复盘
- 照片识别现状、任务照片审核
- 账号登录、云端数据库、多设备同步（数据结构已按目标/任务/记录/形象分对象存储，为同步预留）
- 可安装应用（原生 / PWA 选型待定）
- AI 生成用户肖像、明星形象授权

## 数据说明

所有数据存于当前浏览器 localStorage（键名 `mysystem.v1`）。换设备/换浏览器/清理存储会丢失数据，与 Codex 线原型（grow-with-you 站点）的数据完全独立、互不相通。请用「我的 · 导出数据」备份。

## 与 Codex 版的分工

两条线独立演进、互相不借鉴视觉设计，用于对比不同风格方案。约束（名称、三页面、视觉方向、能力话术边界等）以用户 2026-11-03 提供的需求文档为准。
